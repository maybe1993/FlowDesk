# FlowDesk 工作台

个人与团队一体化的工作管理工具：把**日程、任务、项目、团队成员**和**自动排期建议**串在一条线上。

**零第三方依赖** —— 只需要 Node.js（≥22.5），不需要 `npm install`。

---

## 快速开始

```bash
cd flowdesk

# 可选：先看看环境（Node 版本、端口占用、数据库）
npm run doctor

# 灌一份演示数据（6 名成员 / 4 个项目 / 47 个任务）
npm run seed

# 启动（会自动打开浏览器）
npm start
```

打开 http://127.0.0.1:4173

演示账号：`zhouming@demo.com` / `demo1234`（登录页有「一键填入」按钮）

> **不想用演示数据？** 跳过 `npm run seed`，直接 `npm start`，首次打开网页时会引导你创建管理员账号。

换端口：`PORT=5000 npm start`

首次使用流程：打开网页 → 创建管理员账号（自动登录）→ 空白的仪表盘会给出下一步指引。
每个页面在空数据下都有引导性空状态，不会出现白屏或报错。

## 功能

### 日程安排与查看
- **三种视图**：日 / 周 / 月，热键切换
- **拖拽改期**：把任务从列表或周视图拖到日历某天/某个时段即可改期
- **重复日程**：每天 / 每个工作日 / 每周 / 每两周 / 每月，创建时一次性展开
- **里程碑标记**：项目里程碑直接在日历上显示
- **智能提醒**：逾期、48 小时内到期、里程碑临近、今天的日程

### 任务
- **一句话建任务**（核心便捷特性）—— 在任何输入框写：
  ```
  明天下午3点和陈静对齐上线清单 #发布 P0 2h
  ```
  自动解析出：日期 `10-05`、时间 `15:00`、标签 `#发布`、优先级 `紧急`、预估 `2 小时`
  支持：`下周三` `12月25日` `3天后` `月底前` `每周五` `下班前` `15:30` `90分钟` `阻塞`
  输入时下方**实时显示解析结果**，回车即建
- **三种组织方式**：列表 / 看板（拖拽）/ 按项目分组
- **子任务**、批量操作（状态、优先级、负责人、截止日、归属周、标签、删除）
- **工时记录**：超出预估 1.5 倍自动流转到「待验收」
- **阻塞标记**：标记后自动排期会优先安排「解阻塞」
- 多选方式：点行首圆圈 = 标记完成（可撤销）；按住 `Cmd/Shift` 点行 = 多选

### 项目
- 个人项目与团队项目，支持颜色、标签、优先级、预算工时、描述
- **里程碑**：可勾选完成；完成后自动检查项目是否 100% 并自动收尾
- **下一步（Next Step）**：写一句话，自动排期会优先推进它
- **健康度自动巡检**：对比「已过时间 vs 已完成比例」，给出 `正常 / 需关注 / 风险`
  三级判断，并在项目列表顶部给出**可执行建议**（缩范围、加人、先清逾期…）
- 燃尽数据、8 天投入趋势、参与成员负载

### 团队与人员
- 团队 / 成员 / 角色三层管理
- **成员负载视图**：负载% = 已排工时 ÷ 该成员每周深度工作额度，分 `空闲/正常/偏满/超载`
- 成员档案：职位、部门、汇报关系、技能、每周工时与深度工作额度
- 成员详情：在办任务、月度产出、参与项目、近期完成
- 离职为**软删除**（保留历史数据，不会丢报表）

### 🧠 智能工作安排（核心功能）

打开「智能安排」→ 自动生成你**下周（或本周）每天该做什么**，每一条都附带**人类可读的理由**：

> **薪资档案导入模板设计**（2h）
> ← 已逾期 1 天 · 所属项目「薪资管理系统重构」为紧急 · 里程碑「核算引擎联调通过」6 天后到期

工作原理（`server/planner.js`）：

1. **打分**：逾期天数、截止日临近度、任务优先级、项目优先级、项目健康度、里程碑临近度、是否在进行中、是否置顶、是否阻塞、闲置时长、任务是否过大（过大反而降权）
2. **装箱**：按工作日与每日深度工作额度逐日装填，扣除固定会议占用，每项任务附带 `plannedHours`
3. **约束**：本周内到期的任务最晚排到到期那天；超载项不硬塞，列入「排不下的任务」
4. **产出**：
   - 「最该做的三件事」Top3
   - 逐日安排卡片（每项任务下方显示推荐理由）
   - **建议与提醒**：逾期清理、里程碑临期、大任务拆解、会议占比过高、负载不均、容量过松/过满
   - **负载再平衡建议**（团队视角）：谁超载、谁空闲、建议转移哪几项
   - 阻塞任务前置清单
5. **一键采纳**：把计划写回任务的归属周（可选同时改写截止日），或导出为纯文本周计划

### 报表与复盘
- 日/周/月维度，完成数、工时、项目分布、成员产出对比、状态分布、高频标签
- **周复盘**：本周完成、未完成、**反复顺延的任务**（识别长期拖事）、时间去向、复盘提问清单

### 其他
- **⌘K 命令面板**：搜任务 / 项目 / 成员，或直接输入命令（`新建任务`、`下周安排`、`深色`）
- 亮色 / 暗色 / 跟随系统三主题
- **PWA**：可安装到桌面；Service Worker 采用 network-first 策略 —— 在线时始终取最新代码（避免多文件 ES Module 出现"旧 JS + 新 HTML"白屏），断网时仍能从缓存打开界面并明确提示如何恢复
- 响应式：窄屏自动折叠为底部 Tab 栏
- 数据全部在本机 `data/flowdesk.db`，可随时导出 JSON / 备份 / 恢复
- CSV 导入（支持中文列名，日期可用「下周五」这类说法）

## 界面与可访问性

- **响应式**：≥1180px 三栏 / 860px 单栏 + 汉堡抽屉 / <560px 底部 Tab 栏（实测 390×844 无横向溢出、无文字裁切）

- 尊重 `prefers-reduced-motion`

## 性能实测

压测数据规模：**15 成员 / 20 项目 / 900 任务 + 子任务 / 600 日程 / 4000 工时记录**。

| 场景 | 结果 |
|---|---|
| 全部 24 个接口 | **均 < 40ms**（最慢是导出全量数据 18ms） |
| 智能安排生成（个人 / 团队） | 3~5ms |
| 页面首屏（11 个页面） | 51~121ms |
| 任务列表 | 首屏只渲染 80 条（DOM 约 1300 节点），点「加载更多」增量追加到底 565 条无重复 |

任务列表采用**增量加载**：列表视图每页 80 条；看板与分组视图始终取全量，避免被截断的任务被用户忽略。

并发写入实测：8 并发 × 6 轮 = 48 次写、12 并发 × 10 轮 = 120 次写，**全部成功、零丢失、无 `database is locked`**（SQLite 已启用 WAL + 5s busy_timeout）。

```bash
npm run concurrent                  # 默认 8×6
N=12 ROUNDS=10 npm run concurrent   # 加压
```

## 数据与安全

- 密码用 **scrypt**（N=16384）加盐哈希，不可逆
- session 存 HttpOnly + SameSite=Lax Cookie，服务端只存 token 的 SHA256
- 写操作要求自定义 `X-FD-Client` 头 + JSON content-type（缓解 CSRF）
- 所有写接口都做鉴权校验；管理员操作额外校验角色
- 默认只监听 `127.0.0.1`，不对外网暴露。需要局域网访问时用 `HOST=0.0.0.0 npm start` 并自行评估

## 常见问题

**Q：Node 版本要求？**
A：≥ 22.5（需要内置 `node:sqlite`）。22.x 会由启动器自动加 `--experimental-sqlite` 重启，23+ 直接运行。

**Q：数据存在哪？怎么备份？**
A：`data/flowdesk.db`。设置页 →「数据管理」→「立即备份」或「导出全部数据」（JSON，不含密码）。

**Q：怎么清空重来？**
A：`npm run reset`（重灌演示数据），或手动删掉 `data/` 目录后重新 `npm start`。
